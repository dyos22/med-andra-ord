# Med Andra Ord

Ett webbaserat partyspel i en enda HTML-fil.

Spelet hostas statiskt, till exempel via Netlify, och använder Supabase Realtime
för rum, spelare och poängsynk.

## Filer

- `index.html` - spelet som Netlify publicerar
- `supabase-setup.sql` - SQL som skapar tabellen för spelrum
- `med-andra-ord-qr.png` - QR-kod till den publicerade Netlify-sidan
